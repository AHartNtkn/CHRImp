# CHR Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for independent components and review each integrated task.

**Goal:** Implement the complete approved relational language and local notebook.

**Architecture:** One shared graph records occurrence liveness, variable identity, and work under conditions on explicit choices. Indexed, resumable discovery and serialized conditional updates share applications across alternatives. Causal choice births preserve answer multiplicity independently of condition simplification.

**Tech Stack:** Rust execution process; serde for a common JSON program/inspection model; browser HTML, CSS, JavaScript and SVG for the notebook.

**Spec:** ../../../ARCHITECTURE.md

## Global constraints

- Relation arguments contain only variables; ordinary relations have no built-in term theory.
- Matching does not merge variables. Explicit body equality does. Body locals are fresh per application.
- Only explicit disjunction creates alternatives; other competing applications commit.
- Propagation is once per rule and ordered occurrence tuple per alternative.
- Answers are residual normal forms, with no deduplication.
- Fairness includes internal work, observation and completion; history is opt-in and off by default.
- Both text and direct diagram editing, all specified graph views, step/run/pause/resume and alternative inspection are deliverables.
- Validate general relational regimes, shared execution, low-sharing overhead and continuing reclamation.
